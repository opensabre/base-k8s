# OpenSabre 镜像发布清单

Compose 文件保留 `latest`（管理前端为 `master`）作为默认值，方便开发和首次初始化。
生产环境必须在 `.env` 中显式指定同一批发布标签，避免不同服务漂移到不同构建。

## 发布约定

- 正式版本使用不可变的语义化版本标签，例如 `1.1.2`。
- 同一版本同时保留 commit SHA 标签，用于精确追溯和回滚。
- `latest`/`master` 只作为滚动别名，不用于生产回滚依据。
- 修复代码必须升级补丁版本；禁止重新推送覆盖已经发布的版本标签。

## 部署步骤

1. 复制对应版本清单中的镜像变量到服务器 `.env`。
2. 执行 `docker compose pull`，再执行 `docker compose up -d`。
3. 验证所有容器健康、应用日志和关键 HTTP 接口。
4. 回滚时恢复上一版本清单，再执行同样的 pull/up 流程。

版本清单只保存镜像地址和标签，不保存密码、令牌或其他环境密钥。

# Compose 部署

## 模块介绍

该模块使用 Docker Compose 编排 OpenSabre 的基础设施、基础服务、网关和管理端。

## 功能与使用

- `docker-compose-infra.yml`：基础依赖的编排入口；
- `docker-compose-*.yml`：单个或一组应用的编排入口；
- `config/`：容器挂载/运行配置样例；
- `initdb/`：数据库初始化入口。

具体服务列表、端口、卷和环境变量以对应 YAML 为准。

## 流程

```text
准备环境变量与镜像 → 启动基础设施 → 初始化数据库/配置 → 启动应用 → 健康检查与业务验证
```

## 规划

- 为每个 Compose 组合提供明确的最小启动集和验证脚本；
- 明确本地、集成、生产环境配置差异；
- 提供可审计的初始化与升级脚本执行记录。
